\# LeiloesTDSat



\## Sobre o projeto

Sistema desenvolvido em Java para informatizar as rotinas de uma casa de leilões. Nesta primeira versão, o sistema permite cadastrar produtos e listar os produtos cadastrados, com os dados armazenados em um banco de dados.



\## Tecnologias utilizadas

\- Java

\- NetBeans (IDE)

\- MySQL (banco de dados, script em uc11.sql)

\- JDBC com MySQL Connector/J

\- Git e GitHub (versionamento)
